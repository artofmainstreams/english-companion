# AGENTS.md — English Companion

Desktop-приложение для голосовой практики английского: запись речи,
локальное распознавание (STT), диалог с Ollama.
Python 3.13 + PySide6, MacBook (Apple Silicon); STT — локально
(mlx-whisper по умолчанию, faster-whisper — альтернатива);
Ollama работает на Windows и доступна через SSH-туннель
(http://127.0.0.1:11434).

## Карта модулей

| Путь | Ответственность |
|---|---|
| `main.py` | Точка входа: сборка приложения; STT-бэкенд выбирается через `build_backend(config)`; порядок shutdown: сначала STT, потом аудио |
| `companion/main_window.py` | Окно: история чата, поле ввода, «Записать/Прослушать/Распознать/Сохранить», выбор микрофона |
| `companion/session_controller.py` | Сессия чата: история, модель, запросы к Ollama |
| `companion/ollama_client.py` | REST-клиент Ollama (QNetworkAccessManager) |
| `companion/audio_controller.py` | Фасад аудио: единое состояние IDLE/RECORDING/PLAYING, взаимное исключение запись↔воспроизведение, порядок shutdown |
| `companion/audio_recorder.py` | Запись: устройства ввода, сессия, «готовая» запись; владелец временных файлов |
| `companion/audio_player.py` | Воспроизведение готового аудиофайла; не удаляет переданные файлы |
| `companion/stt_engine.py` | Оркестрация STT: фоновый поток, сигналы, ленивая загрузка модели, shutdown |
| `companion/stt_backends.py` | `SttBackend` (Protocol): MlxBackend, FasterWhisperBackend, `build_backend` |
| `companion/config.py` | `AppConfig`: адрес Ollama, STT (бэкенд, модель, `language=None`, `task=transcribe`) |
| `tests/` · `tools/` · `real_stt_check.py` | Тесты (unittest); диагностика и явная проверка реального распознавания |

## Инварианты

- UI остаётся отзывчивым: распознавание — в фоновом потоке,
  аудио — неблокирующе (цикл событий Qt).
- Запись и воспроизведение взаимно исключаются
  (фасад молча отклоняет вторую операцию).
- Аудио удаляется после завершения работы с ним: STT завершает работу
  и освобождает файл, потом рекордер удаляет временные файлы;
  плеер не удаляет пользовательский файл.
- STT определяет язык автоматически (`language=None`) и сохраняет язык
  речи (русский → русский текст, английский → английский); `task=transcribe`;
  без перевода и LLM-исправлений.
- Расшифровку пользователь отправляет сам (кнопка «Отправить»),
  ничего не отправляется автоматически.

## Команды (из корня проекта, .venv)

```bash
.venv/bin/python main.py                                                  # запуск приложения
QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests  # штатные тесты (без железа)
RUN_AUDIO_TESTS=1 QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests  # + реальная запись/воспроизведение
.venv/bin/python real_stt_check.py [путь/к/записи]                        # реальный STT (отдельная проверка)
```

Установка и опциональные STT-бэкенды — в README.
