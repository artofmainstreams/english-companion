# Ручная проверка «обрыв начала» через наушники (WH-1000XM6)

Задача: установить, **кто** режет начало первого воспроизведения —
приложение или ОС/Bluetooth (A2DP). Автоматически я проверяю только
механику (position, порядок событий); **слышимость** видна лишь на наушниках.

Все тесты: наушники WH-1000XM6 подключены и дефолтны как вывод.
«Первый раз» = первое «Прослушать» после запуска приложения.

## Тест 1 — внешний плеер (САМЫЙ РЕШАЮЩИЙ)
1. В приложении: запись (микрофон гарнитуры) → «Остановить».
   Кнопки «Сохранить» больше нет: запись живёт как **временный файл** до
   закрытия приложения (каталог `english-companion-audio-*` в `$TMPDIR`).
2. Пока приложение открыто, найди файл записи:
   `ls "$TMPDIR"/english-companion-audio-*/`  (на macOS `$TMPDIR` —
   системная временная папка).
3. **Первый раз** воспроизведи этот файл во внешнем плеере через те же наушники:
   - терминал: `afplay "$TMPDIR"/english-companion-audio-*/recording_*.m4a`,
   - QuickTime Player → «Открыть» → файл.
4. Вопрос: начало **целое** или **обрезано**?

- Обрезано → это поведение **ОС/BT** (A2DP первый выход), не лечится задержкой тишины.
- Целое → проблема **в приложении** (создание выхода / переход ввод→выход).

## Тест 2 — зависит ли от ВВОДА (вывод всегда наушники)
- **2a**: ввод = **встроенный микрофон** → запись → стоп → «Прослушать» (1-й раз). Начало?
- **2b**: ввод = **микрофон гарнитуры** → запись → стоп → «Прослушать» (1-й раз). Начало?

- Разница (2a целое / 2b обрезано) → это переход **HFP(ввод) → A2DP(выход)** на гарнитуре.
- Без разницы (оба обрезаны / оба целые) → ввод не причём.

## Тест 3 — без предшествующей записи
- Свежий запуск приложения, запись **НЕ** делать, сразу «Прослушать» готовую запись (1-й раз). Начало?

- Обрезано → холодный **A2DP-выход** (не зависит от записи).
- Целое → зависит именно от предшествующей записи гарнитурой.

## Тест 4 — повторное (контроль)
- Тот же файл, **второе** «Прослушать». (Ожидание по твоему описанию: целое.)

## Что мне прислать
Коротко: `1=целое/обрезано`, `2a=?`, `2b=?`, `3=?`, `4=?`.
И путь к временному файлу записи (если в Тесте 1 было обрезано — приложу
его к анализу).
